# Apéndices del proyecto

Documentación que se entrega junto con el código del **Sistema Integral Web de Control de Producción y
Distribución de Alimentos Congelados (Distribuidora Yaneth)**. Corresponde a los Apéndices A–D descritos en la tesis.

| Apéndice | Contenido | Ubicación |
|---|---|---|
| A | Manual técnico: arquitectura, requisitos, variables de entorno, instalación, operación de servicios, respaldos y mantenimiento | [A_Manual_Tecnico/](A_Manual_Tecnico/) (`.docx` y `.pdf`) |
| B | Manual de usuario por rol y por módulo, con capturas del sistema | [B_Manual_de_Usuario/](B_Manual_de_Usuario/) (`.docx`, `.pdf` y `capturas/`) |
| C | Esquema de la base de datos y diagrama entidad-relación | [C_Esquema_BD/](C_Esquema_BD/) |
| D | Código fuente | Este repositorio (backend) y [distri_yaneth_frontend](https://github.com/DecosUniversity/distri_yaneth_frontend) |

La carpeta [pruebas/](pruebas/) contiene los resultados de las pruebas de las iteraciones 3, 4 y 5.
